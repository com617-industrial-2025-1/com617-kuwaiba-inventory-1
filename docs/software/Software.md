# What We Are Using In This Project

## Software (Core Installations)

These are full applications or platforms that must be installed before anything else.

### Docker

* **Purpose:** Platform used to run and manage containers.
* **Install Link / Source:** https://docs.docker.com/desktop/
* **Notes:** Required to run Kuwaiba.

### Kuwaiba

* **Purpose:** Network inventory and infrastructure management system.
* **Install Link / Source:** https://www.kuwaiba.org/
* **Notes:** Installed and run via Docker.

### JOSM (Java OpenStreetMap Editor)

* **Purpose:** GIS editor used to download, edit, and filter OpenStreetMap data.
* **Install Link / Source:** https://josm.openstreetmap.de/

### FiberQ

* **Purpose:** Predict infrastructure and allows placement of poles and manholes on streets.
* **Install Link / Source:** https://www.fiberq.net/

---

## Extensions / Packages / Libraries / Data

These are add-ons, dependencies, or supporting resources that run on top of the core software.

### Tools / APIs

#### Overpass API / Overpass Turbo

* **Purpose:** Query OpenStreetMap for specific tags and extract map data.
* **Access Links:**

  * https://overpass-turbo.eu/
  * https://export.hotosm.org/v3/

---

### Libraries / Processing Tools

#### osm2streets

* **Purpose:** Converts OpenStreetMap data into a clean street graph.
* **Source / Install Link:**

  * https://github.com/a-b-street/osm2streets

---

### Data Sources

#### OpenStreetMap (OSM)

* **Purpose:** Provides raw geographic and infrastructure map data.
* **Usage:** Accessed through Overpass API and JOSM.
