# 1. Project Summary 
The aim of this project is to create a pipleine that extracts geographic data from OpenStreetMap and UPRN Retrival datasets, predicts optimal fiber infrastruture placement and exports the network inventory into Kuwaiba inventory management. 

# 2. Problem Statement 

• Investigate how Kuwaiba can be used to model services running on a realistic simulated telecommunications network.  

• Produce a worked example and a tutorial showing how a network of real equipment can be modelled. Demonstrate the export (and possibly import) of network inventory in a format (CSV) which can feed a network management system.  

• Simulate your network using real routers (in class) and / or containerlab or GNS3.  

# 3. Project Objectives 

## 3.1 Geographic Data Extraction

•**3.1.1 OpenStreetMap (OSM) Extraction:** The system must allow the user to select a specific area and then extract the street graphs and house locations.  
•**1.1.2 UPRN Retrieval:** The UPRN for each house within the specific area must be retrieved and then linked to the house number based on its latitude and longitude.  

## 3.2 Infrastructure Design and Prediction

•**3.2.1 Infrastructure Rules:** The user should be able to define the specific rules for their network infrastructure (e.g., how many houses to poles, how many poles to cabinets, and the distance between manhole covers).  
•**3.2.2 Automated Placement:** The system should then suggest where each of these artefacts should be placed based on the rules provided.  
•**3.2.3 Network Topology:** The system should record the physical path of the cables required, along with the amount of other artefacts.  

## 3.3 Inventory Modelling

•**3.3.1 Data Formatting:** The locations of each artefact should be recorded based on the format required for Kuwaiba, along with a list of the number of items needed.  
•**3.3.2 Data Export:** The formatted data should then be exported into Kuwaiba.  

## 3.4 Simulation and Visualisation

•**3.4.1 Network Simulation:** Simulate the suggested network within Kuwaiba.  
•**3.4.2 OSM Map:** Produce a map in OSM showcasing the predicted infrastructure.  

# 4. Deliverables 
•**4.1 Worked Example:** A functional model of the simulated network within Kuwaiba.  
•**4.2 Project Report:** Documentation recording how we managed this project and what work we did.  
•**4.3 Project Presentation and Demo:** A Presentation demonstrating this product and the process behind it, which is then delivered to the project's sponsors.
